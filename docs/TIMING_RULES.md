# 计时与测量规范

## 时间基准

使用相机帧提供的采集时间戳或可验证的媒体时间线。记录原始时间戳、时间基准、帧间隔和异常。不要用 UI 时钟或处理完成时间作为飞行时间。

## 事件定义

赛事计时的开始/结束事件必须按目标赛事规则配置。一般训练场景可以提供“出手”和“首次触地/规则终止事件”的候选标记，但不能把某一通用定义冒充所有比赛规则。

## 算法结果

检测模型只提出候选事件。每个候选事件保存：
- 事件类型
- 时间戳/媒体时间
- 置信度
- 证据帧引用
- 是否由用户修正
- 修正前后值与修改时间

## 异常情况

以下情况必须提示不确定性或要求人工复核：
- 飞机飞出画面
- 遮挡或与背景混淆
- 起飞/触地瞬间漏帧
- 可变帧率或时间戳异常
- 视频暂停、剪辑、转码或丢帧
- 无法区分触地与掠过障碍物

## 结果标签

- 自动估算
- 用户复核
- 官方确认

不得仅凭普通单目视频推算真实三维位置、真实三维速度、升力或阻力。二维轨迹必须标注为图像平面轨迹。
