# 高度、下降率与剩余飞行时间估算

## 目标

提供实时、可审计的训练辅助测量：相对地面垂直高度（m）、下降率（m/s）和预计剩余飞行时间区间。任何输出都必须带测量模式、质量状态和采集时间戳。

## 坐标与标定

- 相机坐标系：以相机光心为原点，使用相机内参将像素反投影为射线。
- 地面坐标系：用户在试飞前确认地面参考平面；若场地有已知尺寸标记，可用于尺度/几何校验。
- 飞机测量点：优先使用检测模型输出的机身中心/关键点，不直接把检测框中心当作物理质心。
- 垂直高度：将深度点转换到地面坐标系后，计算其到地面参考平面的有符号垂直距离。
- 相机移动、变焦、镜头切换或标定条件改变时，标定必须失效并重新建立。

## 深度融合

1. 运行时检查 ARCore 和 Depth API 能力；Depth API 不可用时进入降级模式。
2. 为每个相机帧获取匹配时间戳/视场的深度图。
3. 在飞机关键点附近采样小邻域，使用中位数/截尾均值等稳健统计，过滤零值、低置信度和背景边缘。
4. 将相机深度与相机姿态、内参、地面平面结合，转换为垂直离地高度。
5. 计算有效深度比例、样本离散度、目标检测置信度、时间同步误差和标定残差，形成质量分数。
6. 若质量门限不满足，输出 null/relative-only，并说明原因；不能沿用过期高度冒充实时值。

ARCore 深度主要用于场景深度估计，并非专门针对快速运动的小纸飞机测距。动态目标、低纹理背景、运动模糊、遮挡、远距离和深度图延迟均可能导致误差。需要实测验证后才能宣称精度。

## 下降率

- 维护按采集时间戳排序的有限窗口高度样本。
- 先进行异常值门控，再用鲁棒线性回归估计高度斜率。
- 下降率 = -dh/dt；正数表示下降，负数表示上升。
- 窗口长度根据实际帧率与噪声调整；同时输出斜率置信区间/质量状态。
- 对丢帧按真实时间差计算，不假设固定帧率。

## 剩余飞行时间

基础匀速下降估算：T = 当前离地高度 / 当前稳定下降率。该公式仅作基线，不足以覆盖盘旋、滑翔、上升、突变和风场影响。

产品预测策略：
- 先判断目标仍可追踪、地面高度有效、下降趋势稳定且下降率显著大于噪声。
- 结合最近一段时间的下降率变化和训练数据中相似飞行阶段，输出预计时间区间。
- 预测区间应通过留出测试视频校准；没有足够数据时只显示基础估算并明确标注低置信度。
- 若高度/下降率不可靠、飞机正在上升/盘旋、预测窗口过短或飞行状态改变，隐藏数字并显示原因。
- 检测到触地/终止事件后停止预测，记录预测值与实际剩余时间误差。

## 实时性能目标

- UI 仪表更新频率至少 1 Hz。
- 分析目标 10–30 Hz（设备允许时）；以设备实测能力动态调整。
- 优先处理最新帧，使用有界队列，避免延迟累积。
- 记录采集到显示的端到端延迟、有效分析 FPS、丢帧率、温度/降频情况。
- 不为追求 FPS 而牺牲原始录像；可单独降低分析帧尺寸和频率。

## 验证计划

使用已知高度的静态目标、已测量的落点/地面标记，以及多机型、多距离、多背景、多光照测试：
- 高度 MAE、RMSE、95 百分位误差和有效输出覆盖率
- 下降率 MAE 与延迟
- 剩余时间 MAE、预测区间覆盖率
- 设备型号、ARCore Depth 支持状态、拍摄分辨率、FPS、温度
- 纸飞机颜色/折法、运动模糊、遮挡、背景纹理

未完成实测前，产品不得宣称厘米级或其他固定精度。
