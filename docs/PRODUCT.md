# CPAC FLY 产品范围

## 定位

面向纸飞机爱好者的 Android 智能飞行计时与训练分析工具。首版优先验证可靠的视频采集、试飞记录和可人工复核的计时流程，并加入有明确置信度标识的实时高度与下降趋势估算。

## 首版模块

1. 首页与试飞入口
2. 智能拍摄：内置摄像头预览、录像、拍摄状态提示；可配置纸飞机连续离开画面 5 秒至 120 秒后自动结束计时并停止录像，设置本地保存。该能力当前依赖通用模型 airplane 类，纸飞机专用识别接入前仅为实验功能。
3. 识别与追踪：纸飞机检测、连续目标关联、丢失目标状态
4. 计时：出手与终止事件候选、计时结果、人工修正
5. 实时飞行仪表：离地高度估算、下降率、预计剩余飞行时间、数据可信度
6. 飞行分析：慢动作、二维图像轨迹、事件时间线、高度/下降率曲线、预测与实测误差报告
7. 飞机档案：名称、照片、纸张规格/克重、翼展、重量、重心、折法备注
8. 训练记录：视频关联、成绩、设备信息、创建时间和修订记录

不纳入首版：排行榜、线上赛事、社交 feed、外接专业摄像头、强制登录、云端同步。

## 实时高度与预测

- 目标刷新率：界面至少 1 Hz；设备性能允许时，分析链路目标 10–30 Hz。实际频率按机型、分辨率和检测耗时自适应，并显示数据新鲜度。
- 高度含义：优先显示相对地面的垂直高度（米），不是相机到飞机的斜距。只有地面/相机几何和尺度条件足够时才给出米制数值。
- 深度来源：支持设备上可选 ARCore Depth；结合相机内参、设备姿态、地面参考面和纸飞机检测区域估算。设备不支持或场景质量不足时，退化为经过标定的相对高度/图像位置趋势，不伪造绝对米数。
- 下降率：基于带采集时间戳的高度序列计算，单位 m/s；正值代表下降。使用鲁棒平滑/回归抑制抖动，同时保留原始观测用于复核。
- 剩余飞行时间：结合当前高度、下降率、近期趋势及落地/终止事件识别给出区间估计；下降率不稳定、飞机上升/盘旋、深度无效或目标丢失时显示“暂无法可靠预估”。
- 必须显示测量模式、置信度/质量状态、最后更新时间；用户可在回放中修正地面参考或事件。
- 高度预测只作为训练辅助估算，不作为官方比赛成绩或安全保证。

## 用户流程

首页 → 开始试飞 → 检查取景/地面参考 → 录制 → 实时追踪与高度/下降率/剩余时间估算 → 检测候选飞行事件 → 用户确认/修正 → 保存试飞 → 查看分析与历史。

## 成绩状态

- 自动估算：算法候选结果，必须标识为估算。
- 用户复核：用户在视频中确认或修正事件点。
- 官方确认：只有符合相应赛事规则并由授权裁判/组织者确认后才能标记。

## 验收原则

- 相机权限被拒绝时有明确说明和恢复入口。
- 录像失败、存储空间不足、相机被占用时不丢失已有记录。
- 试飞记录可在无网络状态下创建、查看和删除。
- 用户可以修正起止事件，原始自动估算保留在审计字段中。
- 不宣称普通单目视频可无条件还原真实三维轨迹或物理参数。
- 无可靠尺度/地面参考时不输出伪精确的米制高度或剩余时间。
- 记录高度测量来源、质量指标、算法版本、时间戳和预测误差。
