# CPAC FLY 产品范围

## 定位

面向纸飞机爱好者的 Android 智能飞行计时与训练分析工具。首版优先验证可靠的视频采集、试飞记录和可人工复核的计时流程。

## 首版模块

1. 首页与试飞入口
2. 智能拍摄：内置摄像头预览、录像、拍摄状态提示
3. 识别与追踪：纸飞机检测、连续目标关联、丢失目标状态
4. 计时：出手与终止事件候选、计时结果、人工修正
5. 飞行分析：慢动作、二维图像轨迹、事件时间线、训练报告
6. 飞机档案：名称、照片、纸张规格/克重、翼展、重量、重心、折法备注
7. 训练记录：视频关联、成绩、设备信息、创建时间和修订记录

不纳入首版：排行榜、线上赛事、社交 feed、外接专业摄像头、强制登录、云端同步。

## 用户流程

首页 → 开始试飞 → 检查取景 → 录制 → 检测候选飞行事件 → 用户确认/修正 → 保存试飞 → 查看分析与历史。

## 成绩状态

- 自动估算：算法候选结果，必须标识为估算。
- 用户复核：用户在视频中确认或修正事件点。
- 官方确认：只有符合相应赛事规则并由授权裁判/组织者确认后才能标记。

## 验收原则

- 相机权限被拒绝时有明确说明和恢复入口。
- 录像失败、存储空间不足、相机被占用时不丢失已有记录。
- 试飞记录可在无网络状态下创建、查看和删除。
- 用户可以修正起止事件，原始自动估算保留在审计字段中。
- 不宣称单目视频能还原真实三维轨迹或物理参数。
