# CPAC FLY 设备测评清单

本清单用于验证 Debug APK 的实际行为。CI 通过只代表代码编译和单元测试通过，不代表相机、ML Kit 或纸飞机计时已在所有手机上验证。

## 首次安装与离线

- [ ] 安装 Debug APK 并首次启动。
- [ ] 授予摄像头权限。
- [ ] 关闭网络后重新打开应用，确认首页、档案、记录和相机入口仍可用。
- [ ] 确认应用不要求登录，不上传录像，不需要服务器或收费 API。

## 动态目标追踪

- [ ] 进入摄像头页面，等待检测器初始化；首次目标出现可能需要多帧。
- [ ] 使用背景简单、光线充足、目标占画面比例较大的场景。
- [ ] 让一个明显物体在画面内缓慢移动，观察目标 ID 是否连续。
- [ ] 试飞开始后，确认应用锁定一个目标 ID；画面内其他背景目标不应接管该次计时。
- [ ] 记录漏检、ID 变化、帧率、设备发热和相机异常。

## 计时与录像

- [ ] 先开始录像，再标记出手开始计时。
- [ ] 手动标记落地，确认时长和记录保存。
- [ ] 将离画停止阈值设为 5 秒，在干净背景下让锁定目标离开画面，确认倒计时和自动停止。
- [ ] 再分别测试遮挡、快速移动、低光和背景干扰；记录误停/未停情况。
- [ ] 确认录像保存在系统媒体库 Movies/CPAC FLY。

## 视频复核、记录与导出

- [ ] 打开一条含录像的记录，拖动时间线并逐帧前后移动。
- [ ] 标记出手帧和落地帧并保存修正时长。
- [ ] 编辑/删除记录，确认关联数据和录像清理符合预期。
- [ ] 使用“导出 CSV”，确认分享内容包含日期、时长、机型和复核时间戳。
- [ ] 创建、编辑、删除纸飞机档案，并在下一次试飞中关联机型。

## 结果解释

ML Kit 是通用目标检测/追踪器，不是纸飞机分类器。若纸飞机太小、太快、模糊或被遮挡，检测可能漏失；当前自动离画停止应视为实验辅助，重要成绩请在视频复核中人工确认。固定机位/手持跟拍的完整计时补偿、绝对离地高度和真实三维轨迹尚未完成，不应当作已交付功能。
