# 开发路线图

## M0 — 项目骨架
- [x] 建立公开 GitHub 仓库
- [x] 添加产品/架构/计时/许可证文档
- [x] 添加 Compose 首页占位工程
- [ ] 固定 Gradle Wrapper 与 Android Studio 构建环境
- [ ] 首次 Debug APK 构建与安装验证

## M1 — 摄像头与录像
- [x] CameraX Preview（后置摄像头预览接入，待真机验证）
- [x] CameraX VideoCapture（MediaStore 本地 MP4；设备不支持三用例组合时降级为预览+分析）
- [x] 飞机连续未检测到 5–120 秒可选自动停止（当前基于 COCO airplane 临时信号；纸飞机模型接入及真机验证待完成）
- [x] ImageAnalysis 帧采集、RGBA 转换与时间戳接入检测器（待真机验证）
- [x] 摄像头权限请求、生命周期绑定与异常状态处理（待真机验证）
- [ ] 多机型录制测试

## M2 — 预训练 AI 基线
- [x] 接入 MediaPipe Tasks Vision 依赖
- [x] 固定 EfficientDet-Lite0 COCO 模型版本和 SHA-256
- [x] 编写 Android 本地检测器封装
- [x] CI Gradle 构建下载模型并验证 checksum（以成功构建记录为准）
- [x] CameraX 帧接入检测器并显示通用类别检测结果（尚非纸飞机专用检测）
- [ ] 在真实纸飞机视频上评估 COCO 基线的召回率/误检
- [x] 通用检测框 IoU 跨帧关联与稳定 track ID（通用目标追踪，不代表纸飞机识别）
- [ ] 通用模型失效时提供用户点选 ROI + 专用视觉追踪

## M3 — 试飞记录
- [ ] Room 数据模型与迁移策略（当前先用 SharedPreferences 保存轻量试飞记录）
- [x] 飞机档案本地增删改查（SharedPreferences；Room 迁移待做）
- [x] 试飞记录基础保存与列表查看（最多保留 200 条）
- [x] 试飞记录备注编辑与删除
- [x] 试飞记录关联纸飞机档案（含手动与离镜自动停止保存）
- [x] 录像 URI 关联试飞记录（自动清理策略待做）
- [x] 高度样本、测量质量和预测结果本地持久化接口（尚未接入真实测高来源/界面；删除试飞记录时同步清理）

## M4 — 计时工作流
- [x] 摄像头页手动标记出手与落地、实时计时并保存本地记录
- [x] 固定机位/手持跟拍双模式计时分析核心（纯 Kotlin 时间戳事件候选；待接入真实视觉数据）
- [ ] 手持跟拍背景全局运动估计与相机运动补偿实现
- [x] CameraX 实时帧接入平移型全局运动估计诊断（纯平移基线；尚未作为计时补偿输入）
- [ ] 固定机位地面区域标定与触地证据识别
- [x] 已保存录像时间线拖动、MediaExtractor 视频 sample PTS 索引、按 PTS 前后移动与解码帧预览
- [x] 人工标记出手/落地时间戳并按时间差更新记录（sample PTS 与实际显示帧的对应关系仍需真机/可变帧率验证）
- [x] 时间戳递增校验、固定机位出手候选与手持补偿缺失复核测试
- [ ] 可变帧率/视频时间戳异常与真实视频端到端测试

## M5 — 高度与实时飞行指标

- [ ] 1 Hz 最低 UI 更新、设备允许时 10–30 Hz 分析
